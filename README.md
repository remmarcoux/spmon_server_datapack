# S.P. Mon

This Datapack is made by Silver (aka Heart_of_Silver) for Pixelle's Cobblemon server.


## Features

### Custom Recipes

- Added recipe to duplicate Elytras (Note: the recipe does not keep existing enchantments on neither the result nor the original Elytra)
- Adding a recipe to recraft Item Frames into Invisible Item Frames

### NPCs

- Adding Cooldown logic & Behaviors for Trainers
- Adding Battle Once logic & Behaviors for Trainers
- Adding Battle Ending event hooks
- Added Pokémon Trainer Dialogues for customizable NPCs
- Added custom grunts Teams & Dialogues for Team Cutlass

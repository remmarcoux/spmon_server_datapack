# S.P. Mon

This Datapack is made by Silver (aka Heart_of_Silver) for Pixelle's Cobblemon server.


## Features

This datapack adds the following features

### Custom Recipes

- Duplicate Elytras (Note: the recipe does not keep existing enchantments on neither the result nor the original Elytra)
- Recraft Item Frames into Invisible Item Frames
- Enchanted Golden Apples

### Cobblemon NPCs

- Cooldown logic & Behaviors for Trainers
- Battle Once logic & Behaviors for Trainers
- Battle Rewards logic & Behaviors for Trainers
- 3 Pokémon Trainer presets (easy/medium/hard) with skills and random Battle Dialogue for customizable manually spawned trainers
- Custom grunts Teams & Dialogues for Team Cutlass
